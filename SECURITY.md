# Security policy

This policy covers OpenAlex, Unpaywall, Unsub and the code in this GitHub organization.

## Reporting a vulnerability

Please report security holes privately, never in a public issue.

- **By email:** write to security@openalex.org. Only our security team reads it.
- **On GitHub:** open the affected repository's **Security** tab and click **Report a vulnerability**. Only our maintainers see the report. Not sure which repository? Pick the closest one and we'll move it.

Please include what's affected, the steps to reproduce it, what an attacker could do with it, and how to reach you.

## What to expect

- We acknowledge your report within 3 business days.
- Serious holes get fixed in days; we aim to fix everything else within 90 days.
- Once the fix is live, we publish a GitHub security advisory crediting you (unless you'd rather we didn't), and request a CVE when people can run the affected code themselves.
- Please give us up to 90 days before sharing details publicly, and agree the date with us.

We don't pay bug bounties, but we credit every reporter.

The full policy, testing guidelines, scope and past advisories: https://help.openalex.org/security/
